# Сборка и обновление Playgama

Playgama собирается из той же версии игры, что Яндекс и VK: сохраняются актуальные правила подсказок, обучение, поддержка, прогресс и видимость пазлов.

```sh
npm ci
npm test
npm run package:playgama
```

В Windows при запрете запуска npm.ps1 используйте npm.cmd.

Сборка попадает в `dist-playgama/`, новый архив — в `output/playgama/`. В корне ZIP находятся `index.html`, локальный Playgama Bridge 2.3.1, конфигурация и лицензия SDK. Проверка сборки сверяет все public-ресурсы, относительные пути, отсутствие собственного SDK Яндекса и тестовой рекламы. Упаковщик проверяет содержимое и размер ZIP, выводит SHA-256.

Vite выбирает `@game-platform` при сборке: Playgama использует Bridge, остальные режимы — прежний адаптер Яндекса/VK. В Playgama загрузка сохранений и настроек заканчивается до открытия меню; при ошибке чтения игра предлагает повторить загрузку. Ключ и версия сохранения остаются прежними. Настройки включают флаг прохождения обучения; сохранения включают актуальный остаток бесплатных подсказок.

Обновление нужно загрузить в существующую карточку игры в кабинете Playgama, проверить в тестовом запуске и отправить на публикацию. Push в GitHub сам по себе не подтверждает обновление опубликованной игры. Публикация через кабинет в этой задаче не выполнялась.

Локально проверены 83 автоматических теста, TypeScript, production-сборки Playgama, Яндекса и VK и содержимое архива. Реальные рекламные показы, облачные сохранения и поведение опубликованной версии требуют проверки на площадке.
