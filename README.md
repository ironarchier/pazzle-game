# Pazzle Game

Паззл-игра для [Яндекс Игр](https://yandex.ru/games/). Стек: Phaser 4 + TypeScript + Vite.

## Команды

```bash
npm install        # установить зависимости
npm run dev        # dev-сервер на http://localhost:8080
npm run build      # проверка типов + сборка в dist/
npm run preview    # посмотреть собранную версию
npm run typecheck  # проверка TypeScript
npm test           # тесты логики (Node.js 22.18+)
```

## Публикация в Яндекс Игры

1. `npm run build`
2. Заархивировать **содержимое** папки `dist/` (`index.html` должен лежать в корне архива).
3. Загрузить архив в консоли разработчика Яндекс Игр.

## Структура

```
src/
  main.ts            # конфиг Phaser
  scenes/            # сцены игры
public/              # статические ассеты (копируются в dist как есть)
```

## Коллекция и управление

Пять самостоятельных аниме-альбомов: «Токийский гуль», «Атака титанов», «Тетрадь смерти», «Наруто», «Клинок, рассекающий демонов». В каждом — пять персонажей на исходной сетке 4×4 (16 деталей) и суперпазл 5×5 (25 деталей). Все альбомы доступны сразу. Для финала нужны именно пять персонажей его альбома; прохождение другого аниме не открывает чужой финал. Финальный пазл «Токийского гуля» использует сохранённую исходную картинку Канеки `level-1.jpg`.

Главная кнопка открывает выбор аниме, а при незавершённой сборке — продолжает её. Внутри альбома «Дальше» сначала предлагает его непройденные картинки, включая открывшийся суперпазл. После завершения альбома можно выбрать следующее аниме. Сложность суперпазлов не снижается на телефоне; восстановленная сборка сохраняет исходную сетку.

Деталь из лотка нужно потянуть вверх, лоток — листать вбок или колёсиком. Любую деталь можно закрепить в её правильном месте. Свободные соседние детали соединяются в переносимые группы. «Образец» открывает исходную картинку; закрыть её можно касанием фона, надписью или Escape. «Подсказка» предлагает коснуться детали и подсвечивает её место без автоматической установки. В этом режиме лоток также можно листать.

После действий автоматически сохраняются одна текущая сборка, порядок лотка, свободные группы, установленные детали, зерно генерации формы, обучение и собранные картинки всех пяти альбомов. Координаты групп записываются относительно поля. Аниме-сохранение: `pazzle-game:anime:save:v1`. Старые ключи `pazzle-game:save:v1` и `pazzle-game:level` остаются нетронутыми и не засчитываются за новых персонажей: это другой набор изображений. При недоступном хранилище игра продолжает работать в памяти, но перезагрузка не сохранит новые действия. Выбор другой картинки запрашивает подтверждение замены незавершённой сборки. Повторная сборка не увеличивает прогресс.

Происхождение изображений и промпты: [ASSETS.md](ASSETS.md). Прежняя коллекция `journey-*.jpg` сохранена в файлах, но не используется в аниме-альбомах.

## Проверка изменений

Автотесты проверяют независимое открытие всех пяти финалов, выбор следующего персонажа внутри альбома, уникальность 30 прохождений, наличие всех изображений, изоляцию старых сохранений, валидацию и запись сборок, недоступное хранилище, воспроизводимость формы на сетках 4×4 и 5×5, установку внутренней детали, обучение, группы и прерванные анимации, восстановление на другом поле, подсказку, отмену жеста и однократную победу. Тесты сцен используют замену рендерера Phaser и не проверяют реальные мышь/тач, звук, WebGL или внешний вид.

При переходе на аниме-альбомы интерфейс проверен во встроенном браузере на размерах 1280×720 и 390×844: главная страница, список альбомов, карточки «Токийского гуля», закрытый суперпазл, подтверждение смены картинки, подсказка, перенос и установка детали. После перезагрузки проверены кнопка «Продолжить», сохранённая деталь и счётчик. Это проверка в браузере с мобильным размером окна, а не на физическом телефоне. Полное ручное прохождение всех 30 пазлов, реальные тач-жесты и звук на устройствах не проверялись. Публикация не выполнялась.
