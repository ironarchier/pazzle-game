# Обложки для Playgama

Подготовлены 29 октября 2026 года из результатов встроенного image_gen от 28 октября.

| Поле в кабинете | Файл | Размер |
| --- | --- | --- |
| Square 1:1 | `cover-square-800x800.png` | 800 × 800 |
| Portrait 9:16 | `cover-portrait-1080x1920.png` | 1080 × 1920 |
| Landscape 16:9 | `cover-landscape-1920x1080.png` | 1920 × 1080 |

Все три обложки — PNG с английским названием **ANIME PUZZLES**. В `playgama-covers.zip` находятся только эти три готовых файла. Оригиналы генерации сохранены в `sources/`. Финальный экспорт приведён к указанным размерам с сохранением пропорций; исходники не перезаписаны.

Использован встроенный инструмент `image_gen`, без CLI/API-скриптов. Основа персонажа: `public/images/anime/tg-touka.jpg`. Игровая палитра и механика: `output/franchise-qa/mobile-puzzle.png`. Для вертикального и горизонтального вариантов квадратная обложка служила дополнительным образцом оформления. Промпты: `sources/PROMPTS.md`.

Это рекламные иллюстрации, не скриншоты игрового процесса. Ранее отмеченные ограничения модерации по использованным персонажам сохраняются; создание обложек их не устраняет.

- `promo/icon-512.png` — старая иконка 512 × 512; не заменяет обложку 800 × 800.
- `output/franchise-qa/mobile-puzzle.png` — скриншот игры 390 × 844.
- `output/franchise-qa/mobile-album.png` — скриншот альбома 390 × 844.
